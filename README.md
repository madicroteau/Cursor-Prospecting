# Account Intel

A simple interview prototype for enterprise sales prospecting.

Enter a company name and website, then research publicly available information into a sales dossier.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current status

- Home page with Company Name, Company Website, and RESEARCH ACCOUNT
- Full account results page layout with all dossier sections
- Sample/placeholder content only (clearly labeled)
- Live web research and AI analysis come next

## Results page sections

Executive Brief, Why Now, People, Hiring, Initiatives, Technology, Financial / Public Information, Prospecting Plan, Sources

Important claims are labeled as FACT, INFERENCE, or SALES HYPOTHESIS.
